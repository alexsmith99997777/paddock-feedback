# Paddock feedback

Feedback on Paddock, a Mac client for [Herdr](https://herdr.dev), collected while it's in daily use.

Send it from the app with **Help › Send Feedback…** (`⇧⌘/`), or [open an issue](../../issues/new?template=feedback.md) by hand.

Please don't include private code, file paths or credentials: this repository is public.

Labels: `feedback` new, `bug` the app doesn't do what the design says, `design` the design itself needs to change, `ready` diagnosed and queued for the next round of work.
